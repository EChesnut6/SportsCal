# SportsCal
A minimal easy to use sports calendar to see when the events you care about are happening.


## Prompt
1. Create a grid layout calender with a minimalist dark mode UI
2. Use ESPN APIs to pull game and event data for the following leagues: NFL, NBA, MLB, NHL
3. User should be able to favorite leagues and teams
4. Include toggles for each league and team to show/hide the events
